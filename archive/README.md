# Archivo del proyecto

El contenido de esta carpeta se conserva para compatibilidad o referencia histórica y no forma parte de las pantallas activas.

- `v1/public/`: reglas y adaptadores V1 que todavía carga el runtime de Arena del servidor. No eliminar mientras exista esa dependencia.
- `legacy-v1.6/` y `analytics-v1/`: snapshot y simulaciones anteriores.
- `docs-v1.6/`: guías, diseños y planes reemplazados por los documentos actuales de `docs/`.
- `reference-images/`: mockups anteriores; las imágenes activas de Unity viven en `unity/FactoryWars.Unity6/Assets/Resources/`.
- `exports/` e `installers/`: paquetes exportados e instalador conservados fuera del árbol activo.
- `unity-local-state/`: preferencias y registros locales previos del Editor; no son necesarios para abrir el proyecto.

El proyecto actual está descrito en el [README principal](../README.md).
