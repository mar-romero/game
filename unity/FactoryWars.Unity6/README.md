# Factory Wars · Unity 6 mobile client shell

This is a parallel, original Unity client shell for the mobile-first direction. It does not replace or modify the current HTML/CSS/JavaScript client. Open this folder as a Unity project with Unity 6.0, create/open a scene, and press Play; the runtime bootstrap creates the vertical interface and procedural 3D world without scene assets.

## Current screens

- **Megafábrica:** animated procedural floating factory, module and research cards, and explicit empty states for account-backed production/resources.
- **PvP:** procedural arena preview, a visual action-card hand, and a matchmaking action seam that reports that no service is connected.
- **Ranking:** explicit unavailable/unauthenticated state; it does not display fabricated standings.
- **Civilizaciones:** the existing four catalog entries (`forge`, `bastion`, `swarm`, `nexus`) and their currently documented Megafábrica/Arena bonuses. Local selection only changes the preview; it does not persist or lock a game profile.

There is no Imperio tab. “Megafábrica” is the persistent factory presentation from the requested menu set.

## Build targets

In Unity Hub, install Unity 6.0 and add the Android Build Support module (SDK/NDK/OpenJDK), iOS Build Support (macOS/Xcode is required to produce/sign the iOS app), and WebGL Build Support. In **File → Build Profiles**, create a profile for **Android**, **iOS**, or **Web** (Unity's WebGL target). Set portrait orientation for mobile profiles. The same scene/runtime code is used by each build target; browser and native performance still need device testing.

The project includes a minimal serialized entry scene in `Assets/Scenes/FactoryWarsMobile.unity`; the bootstrap creates the interface and 3D world at runtime. Web builds need a host configured for Unity's generated files and compression headers; GitHub Pages deployment has not been configured or tested here.

## Integration status

| Existing system | Unity client status |
|---|---|
| `public/game/domain/empire/catalog.js` | Civilization IDs, labels and stated bonuses are represented in the presentation. The JavaScript catalog is not imported or shared as runtime code. |
| Megafactory save, production, upgrades, research, prestige | Not connected. Values remain unavailable instead of being fabricated. |
| Arena `Match` rules, bot, actions, rewards | Not ported or connected. The PvP view is a presentation preview; its card icons are not gameplay commands. |
| Supabase identity, profile, matchmaking, leaderboard | Not connected. Buttons emit named integration events (`empire.open_research`, `arena.request_matchmaking`, `ranking.connect`). |
| Server-authoritative competitive results | Not connected. No ranking or rewards are generated by this client. |

`FactoryWarsMobileApp.onIntegrationRequested` is the explicit seam for future adapters. No external packages beyond Unity UI (UGUI) are required. UI pictograms use short text labels for font portability; runtime visuals use Unity primitives and built-in UI. They are an original stylized prototype, not Clash Royale artwork or asset parity.
